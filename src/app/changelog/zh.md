- 移除了七条界面从未使用的内部通道。它们各自都是被攻破的窗口可以触达、却对任何人都没有用处的开口——是 Office 文档还交给外部程序打开的年代留下的。你在应用里能做的事没有任何变化

### 内部改进

- 证书签名工具现在由测试完整跑过一遍，而不只是测试它底层的那几个函数

## 3.3.1 — 2026-09-05

**应用本身没有任何改动。**这个版本和 3.3.0 是同一份程序；如果你已经装了 3.3.0，升级后不会有任何差别，也不必去找

改的是下载页面。macOS 对任何它无法验证签名的应用都会说 *「Magies Office 已损坏，无法打开」*，而本项目的安装包没有签名——于是有人真的把一个完好的文件删掉了。页面现在会先说明这一点，再给出解决办法

## 3.3.0 — 2026-09-05

### 在 PDF 上高亮和手绘

- **选中文字即可高亮，也可以用画笔在页面上写画——而且这些标记会留下来。**它们作为真正的批注写进文档，所以高亮下面的文字仍然是文字，其他 PDF 阅读器也能看到、移动或删除你画的内容
- 标记和「旋转页面」进入同一条撤销历史，⌘Z 可以撤回。文档会被视为已修改，因此关闭标签页时会先询问，⌘S 会把它写进文件
- 跨越分页的选区做高亮时，两页都会正确标记，各自落在该在的位置

这两个功能在 3.2.0 中被移除，因为它们什么也留不下——笔一抬，画的东西就消失了。现在标记有地方可去，它们回来了

### 内部改进

- 构建与代码检查工具链更新（Vite 8、ESLint 10），应用启动体积略有减小

## 3.2.4 — 2026-09-05

### 你的修改不会丢

- **PDF 保存过程中做的编辑，可能被标记为已保存却根本没写进文件。**保存写入的是你按下保存那一刻的文档，稍后才完成；这中间输入的内容会被当成已经写入。标签页于是显示没有修改，关闭时也不再询问。另存为存在同样的缺口
- **同时保存两个 Office 文档时，可能结束错误的那一个。**先到的那个完成事件会结束正在等待的任何一个，于是较慢的保存被当成已完成，标签页关闭时以为改动已经落盘。现在保存按文档分别跟踪

### 安全

- **一份正确签名的 PDF 可能被报告为签名无效。**大约每几百份签名里有一份，其末尾字节恰好被填充清理当成了填充，检查读到的就是一段被截断的签名，于是判定为格式错误。文档本身从来没有问题；在这个版本里重新验证一次就会如实显示
- 在区分大小写的 macOS 卷上，对一个文件的覆盖授权可能覆盖到另一个文件。此前假定所有 Mac 都把 `A.pdf` 和 `a.pdf` 当作同一个文件；现在改为询问文件系统，而不是假定
- 本地 API 对「同时运行多少个工具」的限制此前只作用于异步请求。普通请求是同样的工作量，却可以无限量地同时发起

### AI 助手

- **联网搜索完全不起作用。**可以配置，但搜索工具从未被注册——助手根本不知道自己有这个能力
- 对同一个文件连续运行两个工具时，第二个会拿到空文件并报告文档已损坏
- 同时打开的两个 Office 文档可能互相显示对方的图片
- 回复里那些窗口本来就不允许加载的图片，现在显示为它的文字说明，而不是一张破图

### 其他修复

- 搜索长 PDF 时：上一次搜索还没结束就输入新词，旧结果可能仍然留在屏幕上
- Linux 上，仅大小写不同的两个文档重新被视为两个文档，不再共用一个标签页
- 同一时刻重复打开同一个 Office 文件，不再遗留多余的编辑器会话

## 3.2.3 — 2026-09-04

### AI 助手

- **把 Magies Office 接入编程 CLI 时，写进去的配置根本无法启动。**配置里的路径指向服务端的一份副本，而那份副本加载不了自己的依赖，结果是智能体完全拿不到 Magies 工具，且没有任何提示说明原因。只影响安装版；从源码运行时接入的一直是好的

如果你的 CLI 是旧版本接入的，请到设置里重新接入一次以替换掉那条配置

## 3.2.2 — 2026-09-04

### 安全

- 本地 API 的健康检查不再向没有令牌的调用者报出版本号。它对任何人都会回答「我还活着」——这是应该的——但在 API 对局域网开放时，这条回复同时告诉了网内所有人当前跑的是哪个构建，而本应用内置了数个引擎，它们的安全公告都可以按版本号查到

### 打印

- 打印不再频繁询问预览是否就绪、以至于把它拖垮。机器繁忙时这会让打印本身失败——比 3.2.1 引入这项检查所要防止的那张白纸更糟

## 3.2.1 — 2026-09-04

### AI 助手：CLI 智能体恢复可用

- **Codex、Gemini 和 Grok 的对话会直接失败。**它们启动时带的参数是各自 CLI 已经不接受、或者从来就没有的，于是一轮对话以一条关于参数的错误收场，什么也没做。现在每个参数都以所装程序自己的说明为准
- Grok 的会话是按文件夹保存的，要它继续一个并不存在的会话会让这轮直接结束。现在它会改为开启一轮新对话
- 六个智能体都能选择模型档次了。Cursor 的列表早已过时——原先提供的 7 个模型里有 5 个已经不存在——现在直接用它的 CLI 给出的那份；Antigravity 补上了它一直支持的推理档位

### 打印

- **长文档有可能打印成一页空白**，出现在机器繁忙、预览尚未渲染完成就送出打印任务的时候。现在不再靠估算等待多久：每一页都真正就位之后才开始打印

## 3.2.0 — 2026-09-04

### 安全

- 读取文件现在由主进程逐个授权，界面无法凭一个路径字符串读到任意文件。打开文档、把文件拖进窗口、从对话框或最近列表中选择，都会授权那个文件，仅此而已。此前任何路径都读得到，而且读过之后还会顺带获得覆盖它的权限
- 选择外置转换器不再为了选中它而把整个程序读进内存，超过 512 MB 的转换器现在也能正常选择

### 你的修改不会丢

- Office 文档的「保存并关闭」现在会等字节真正落盘再关标签页。此前只要发出保存请求就关，没写完的那次保存会连同修改一起消失
- 保存失败会告诉你。此前标签页仍然显示为已保存，磁盘上却还是旧内容，之后关闭它也不会有任何提示
- 关闭窗口或退出应用时，会询问有未保存修改的文档。此前只有关闭标签页会问
- 撤销回到上次保存的那个版本时，文档重新被视为已保存，而不是永远停留在已修改
- 把 Office 文档输出为 PDF 不再算作保存了它。文档本身并没有被写入，所以未保存状态会保留下来 —— 对话框里给出的文件名现在也以 .pdf 结尾

### 打印

- 打印 PDF 打印的是 PDF。此前打印的是应用窗口 —— 工具栏、侧边栏、各种面板 —— 而且只包含恰好在屏幕上的那几页，六十页的文档打出来是几屏界面。快捷键、工具栏按钮和文件菜单现在做的是同一件事，失败也会明确提示，而不是毫无反应

### Office 文档

- 打开一个已经打开的文档，会聚焦到持有它的标签页，而不是在背后再建一个无人引用的编辑器会话。每个被遗弃的会话都在临时目录里留着一份文档副本，且再也没有东西能删掉它
- 一次打开多个文档时，其中一个转换失败，不再把其余已经建好的会话丢在那里
- 退出应用时会关闭编辑器并清除所有临时副本。此前没有任何代码做这件事，副本会一直堆积
- AI 连续改写多个文档时，每个标签页都会重新载入。此前只有最后一个会；其余的仍指向已经关闭的会话，且无法恢复

### 其他修复

- 打开自动更新后，周期检查会立即开始，不需要重启
- 划词菜单出现在你选中的文字旁边，而不是出现在这段文字在文档顶部时所处的位置
- 悬浮提示上的角标现在居中了

### 移除

- 自由画笔和文本高亮取色板已移除。这两项都不保存任何东西 —— 画笔的笔迹在松开按键时就消失，取色板不会高亮任何内容，而且由于两者都不会把文档标记为已修改，关闭标签页时也不会有任何询问。等批注能真正写进文件时它们会回来

### 内部改进

- lucide-react 升级到 1.27，concurrently 升级到 10

## 1.0.4 — 2026-07-29

### 从工具箱变成文档编辑器

- **文档标签页** —— 可以同时打开多个 PDF，各自独立的修改历史、缩放和阅读位置。打开已经开着的文件会切到那个标签，而不是再开一个
- **工具直接作用于当前文档** —— 文档在屏幕上时选一个工具，它就对这个文档运行，结果直接回到页面里，`⌘Z` 可以撤销。不用再走「找文件 → 拖进去 → 运行 → 保存 → 重新打开结果」这一圈

- **连续滚动** —— 所有页面在一列里连续滚动阅读，不用再点箭头一页一页翻
- **适合宽度 / 适合整页**，按住 `⌘` 滚动（或触控板捏合）以光标为中心缩放，按住空格拖动平移
- **文字可以选中和复制**，`⌘F` 全文查找，支持上一个 / 下一个、结果计数和循环
- 高分屏上文字不再发虚，页面重绘也不再先闪一下白

### 打开与保存

- **在访达或资源管理器里双击 PDF 就能用 MagiesPdf 打开**。它注册为候选处理器，会出现在「打开方式」里，但不会抢走你原来的默认程序
- 把文件拖到窗口任意位置都能打开，不用再对准那个虚线框；macOS 上拖到程序坞图标也行
- **`⌘S` 直接覆盖原文件**，不再每次都弹「另存为」对话框；`⌘⇧S` 才是另存为
- 补齐了整套快捷键：`⌘O` 打开、`⌘W` 关闭、`⌘Z` / `⌘⇧Z` 撤销重做、`⌘F` 查找、`⌘K` 搜索工具、`⌘+` / `⌘-` 缩放、`⌘0` 实际大小、`⌘1` 适合宽度、`⌘2` 适合整页，以及翻页键和 Home / End
- 撤销新增了对应的重做

- 启动更快：设置、流水线、批量处理和签名这几个页面改为打开时才加载

### 正确性

- **编辑不再把你正在看的地方挪走** —— 旋转上方的某一页后，阅读位置仍停在原处
- 第一次编辑不再引起整篇文档重新缩放
- 离开文档不再丢失修改，所以「确定要离开吗」的拦截去掉了；只有关闭标签时才会问
- `⌘S` 只能覆盖本应用自己打开过的文件，其他路径一律拒绝

## 1.0.3 — 2026-07-28

### 打开 PDF，直接在上面改

- **新增查看器** —— 首页即可打开 PDF 阅读：左侧页面缩略图、缩放、翻页。已选文件和工具产出的 PDF，旁边的眼睛图标也能直接预览
- **页面编辑** —— 在缩略图上直接旋转、删除、拖拽调整页序
- **框选涂黑** —— 在页面上拖出一块区域，其中内容被永久删除，不是盖个黑框
- **点击盖章** —— 选一张 PNG/JPG 公章或签名图，点哪盖哪
- **就地填表单** —— 直接在页面上浮出的输入框里填写，不用再手打字段名
- 支持撤销（10 步）、另存为，以及「选择工具」——带着你的修改跳到 58 个工具中的任意一个

### 正确性

- 旋转过的页面上点击位置不再错位：渲染显示的是旋转后的页面，而绘制层用的是未旋转的原始页面，两者现已对齐
- 加密 PDF 可输入密码打开，密码会自动用于后续每一次编辑。由于保存后会丢失加密，查看器会明确提示，而不是让它悄悄发生
- 字段名中含 `=` 或换行的表单域会被跳过并提示，而不是把值写进错误的字段
- 开启自动更新后会自动下载，「重启安装」可正常工作

## 1.0.2 — 2026-07-27

### 安全与可靠性

- 隔离 Electron 渲染与打印窗口，校验 IPC 调用来源，并限制隐藏窗口联网
- 为 REST API 增加输入限制、安全文件名、局域网 HTTPS、异步任务与取消能力
- 强化 PDF 动作清理与 OOXML ZIP 解压大小限制
- 用维护中的 SheetJS 0.20.3 替换 npm 上存在漏洞的 `xlsx` 0.18，并在 CI 审计随应用发布的依赖
- OCR 缺少语言模型时必须获得明确下载授权

### 功能与工程

- 新增本地 P12/PFX PDF 证书签名与签名字节完整性校验
- Office 导入导出优先使用已配置的外部转换器
- 工具总数增加到 58，并加入覆盖率门禁、CI 与依赖维护
- 未签名应用的更新下载和安装保持手动确认

### 首次打开（未签名安装包）

- **macOS**：执行 `xattr -dr com.apple.quarantine /Applications/MagiesPdf.app`，或右键 → 打开。Intel 用 `mac-x64`，Apple Silicon 用 `mac-arm64`
- **Windows**：SmartScreen → 更多信息 → 仍要运行
- **Linux AppImage**：先 `chmod +x` 再运行

## 1.0.0 — 2026-07-27

**MagiesPdf** 首个公开开源版本。

### 亮点

- **57 个本地 PDF 工具**（整理、转换、安全、编辑、高级）
- **抽屉侧栏** — 点击分类展开工具
- **流水线** — 内置预设，支持保存/加载与 JSON 导入导出
- **批量处理** — 支持递归选择文件夹
- **本地 REST API**（默认关闭，需 Bearer 令牌）
- **可见签名**（手绘 / 图片 / 文字）— 非证书数字签名
- **品牌图标** 覆盖 macOS / Windows / Linux 安装包

### 本版本明确不做

- 不做 PDF **证书**（PKCS#7 / X.509）签名或校验
- 不做安装包 **代码签名 / 公证**（开源分发）

### 首次打开（未签名安装包）

- **macOS**：安装后执行 `xattr -dr com.apple.quarantine /Applications/MagiesPdf.app`，或右键 → 打开
- **Windows**：SmartScreen → 更多信息 → 仍要运行
- **Linux AppImage**：`chmod +x` 后运行

### 平台（与 MagiesTerminal 一致）

- **macOS**：DMG + ZIP · arm64、x64（Intel）
- **Windows**：NSIS + portable + ZIP · x64、arm64
- **Linux**：AppImage、deb、rpm、pacman · x64、arm64

### 升级（双链）

- 设置 → 检查更新（仅安装包）
- 大陆优先 `dl.magies.top/magiespdf/stable`，海外优先 GitHub `Zhangwei930/MagiesPdf`
- 任一源失败自动切换另一源
