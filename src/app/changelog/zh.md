## 3.0.0 — 2026-08-07

### Office 文档在本窗口内打开

- **Word、表格、演示文稿现在以标签页的形式在 Magies Office 内打开**，不再交给另一个程序处理；PDF 和文档之间切换只是换个标签，窗口也只保留一套工具栏
- 编辑器是内嵌的 **ONLYOFFICE Document Server 9.4.0**，通过本机回环地址提供服务；不需要架服务器，也不需要登录账号，文档不会离开这台机器
- 文件菜单可以新建、打开和**另存为**，作用于当前标签页里的文档
- 完整的中西文字体列表，别处排好的文档打开时能用上它指定的字体
- 表格支持数据透视的字段区域、排名和透视图，表头保持可读
- LibreOffice 仍然随包提供，继续负责 PDF 预览和格式转换——内嵌引擎替换的是*编辑*路径，不是整个运行时

### PDF 工具改为任务窗格

- 工具以**右侧任务窗格或紧凑对话框**的形式打开，不再占满整个窗口，设置选项时页面始终可见
- 支持一步完成和确认后应用两种方式，并回报处理后的文件大小
- **强力压缩**会重新编码图片，而不只是重新打包数据流，真正的体积收益来自这里；标准压缩仍然无损
- 新增创建表单域，以及原位替换文字

### 更清爽的起始页

- 文档放在起始页中间，工具箱收起，搜索框只留一个
- 全新分层应用图标，macOS 和 Windows 同步更新

### 打包

- 引擎的共享部分在 CI 中统一构建一次，各平台的转换器从各自的安装包中准备；缺少引擎时打包直接失败，而不是产出一个打不开文档的应用
- 包内不再包含用不到的 PDF 编辑器、44 种用不到的语言和模板库
- 更新 `pdfjs-dist` 与 `js-yaml`，修复两条高危公告（GHSA-hq66-cqwq-w95j、GHSA-5p4m-2wfm-xmqj）

## 2.0.1 — 2026-08-01

### AI 办公助手

- 支持 OpenAI 兼容聊天智能体（OpenAI、DeepSeek、通义、Ollama 等），工具调用需确认，并加密保存 API Key
- 授权办公目录后，可调用本地 PDF 工具与白名单内的 Office 操作；文档字节不会整份上传，仅在确认后发送有限纯文本预览
- 本机 MCP Server，以及加密保存的外部 MCP 配置（stdio / Streamable HTTP），外部工具同样需确认
- 保存有界、已脱敏的任务历史便于复用

### 双模式受控自动化

- **审核队列与无人值守**：文件夹自动化可先排队待你确认，也可在你勾选的本地 Office 工具白名单内无人运行
- **可信文档宏**（ODT/ODS/ODP 内的 LibreOffice Basic）始终需要交互确认，且绝不会进入无人值守规则
- 首页同时提供手工办公与 AI 自动办公入口

### Office 自动化动作

- Word：读内容与修订、接受/拒绝全部修订、替换（普通或修订模式）、插表/图、页眉页脚、批注
- Excel：读写区域、排序、自动筛选、格式、条件格式、图表、数据透视表
- PowerPoint：读取、替换文本、增/复制/删幻灯片、插图/表、演讲备注
- 模板单次/批量填充、批量转 PDF、工作区扫描与归档
- 写操作一律生成不覆盖源文件的新副本

### 修复与说明

- 通过 macOS 服务路径启动捆绑的 LibreOffice，打包应用更稳定
- 对齐 Magies Office 2.x 产品说明、未签名首启步骤与应用内更新日志

## 2.0.0 — 2026-07-31

### 本地 Office 工作台

- **在同一个桌面首页创建、打开和编辑 Word、Excel、PowerPoint 文件**，并提供最近文档、重命名、移除和移到废纸篓等常用操作
- **安装包已经内置 LibreOffice 26.2.5**，客户只需安装一次 Magies Office，不需要再次安装编辑器，也不依赖在线服务
- 文档始终保留在本机；Office 转 PDF 及受支持的 Office 格式转换默认使用内置本地引擎
- PDF 继续使用 Magies 原生工作区，Word、表格和演示文稿则使用随客户端安装的桌面编辑器

### AI 办公助手

- 支持 OpenAI 兼容接口（含 Ollama 等本地模型）
- 智能体可在你授权的目录上调用 PDF 工具与白名单内的 Office 操作；聊天中的工具调用需你确认
- 支持自动化规则、任务历史、本机 MCP，以及加密保存的外部 MCP 配置

### PDF 操作更简单

- 新建空白 PDF 后直接进入编辑器，并可点击页面位置插入文字
- 工具表单只把常用选项放在前面，低频设置收进更多选项，同时加入页码范围快捷按钮、分组选项和真正的文件选择器
- 首页、文档操作和编辑入口采用更简洁的办公软件布局，减少安装说明和中间步骤

### 安装包与兼容性

- macOS Intel/Apple Silicon、Windows x64/ARM64、Linux x64 安装包分别内置并校验匹配架构的 LibreOffice
- 上传安装包前校验运行时架构、版本、开源声明，并在对应系统上执行原生启动测试
- 安装包保持免费开源且不签名；macOS Gatekeeper 或 Windows SmartScreen 首次打开时可能需要手动确认
- 界面产品名为 **Magies Office**；发布文件名仍使用 `MagiesPdf-` 前缀

## 1.0.4 — 2026-07-29

### 从工具箱变成文档编辑器

- **文档标签页** —— 可以同时打开多个 PDF，各自独立的修改历史、缩放和阅读位置。打开已经开着的文件会切到那个标签，而不是再开一个
- **工具直接作用于当前文档** —— 文档在屏幕上时选一个工具，它就对这个文档运行，结果直接回到页面里，`⌘Z` 可以撤销。不用再走「找文件 → 拖进去 → 运行 → 保存 → 重新打开结果」这一圈
- **顶部功能区** —— 按分类分组的命令条取代了左侧 268 像素的工具树，文档区因此宽了约 250 像素
- 需要多个文件的工具（比如合并）仍然打开自己的页面，但当前文档已经在文件列表里了
- 关闭有未保存修改的标签会问你：保存并关闭 / 不保存 / 取消

### 阅读

- **连续滚动** —— 所有页面在一列里连续滚动阅读，不用再点箭头一页一页翻
- **适合宽度 / 适合整页**，按住 `⌘` 滚动（或触控板捏合）以光标为中心缩放，按住空格拖动平移
- **文字可以选中和复制**，`⌘F` 全文查找，支持上一个 / 下一个、结果计数和循环
- 高分屏上文字不再发虚，页面重绘也不再先闪一下白

### 打开与保存

- **在访达或资源管理器里双击 PDF 就能用 MagiesPdf 打开**。它注册为候选处理器，会出现在「打开方式」里，但不会抢走你原来的默认程序
- 把文件拖到窗口任意位置都能打开，不用再对准那个虚线框；macOS 上拖到程序坞图标也行
- **`⌘S` 直接覆盖原文件**，不再每次都弹「另存为」对话框；`⌘⇧S` 才是另存为
- 补齐了整套快捷键：`⌘O` 打开、`⌘W` 关闭、`⌘Z` / `⌘⇧Z` 撤销重做、`⌘F` 查找、`⌘K` 搜索工具、`⌘+` / `⌘-` 缩放、`⌘0` 实际大小、`⌘1` 适合宽度、`⌘2` 适合整页，以及翻页键和 Home / End
- 撤销新增了对应的重做

### 更快

- 编辑之后只重画真正受影响的页面，其余页面保留已经画好的内容
- 启动更快：设置、流水线、批量处理和签名这几个页面改为打开时才加载

### 正确性

- **编辑不再把你正在看的地方挪走** —— 旋转上方的某一页后，阅读位置仍停在原处
- 第一次编辑不再引起整篇文档重新缩放
- 离开文档不再丢失修改，所以「确定要离开吗」的拦截去掉了；只有关闭标签时才会问
- `⌘S` 只能覆盖本应用自己打开过的文件，其他路径一律拒绝

## 1.0.3 — 2026-07-28

### 打开 PDF，直接在上面改

- **新增查看器** —— 首页即可打开 PDF 阅读：左侧页面缩略图、缩放、翻页。已选文件和工具产出的 PDF，旁边的眼睛图标也能直接预览
- **页面编辑** —— 在缩略图上直接旋转、删除、拖拽调整页序
- **框选涂黑** —— 在页面上拖出一块区域，其中内容被永久删除，不是盖个黑框
- **点击盖章** —— 选一张 PNG/JPG 公章或签名图，点哪盖哪
- **就地填表单** —— 直接在页面上浮出的输入框里填写，不用再手打字段名
- 支持撤销（10 步）、另存为，以及「选择工具」——带着你的修改跳到 58 个工具中的任意一个

### 正确性

- 旋转过的页面上点击位置不再错位：渲染显示的是旋转后的页面，而绘制层用的是未旋转的原始页面，两者现已对齐
- 加密 PDF 可输入密码打开，密码会自动用于后续每一次编辑。由于保存后会丢失加密，查看器会明确提示，而不是让它悄悄发生
- 字段名中含 `=` 或换行的表单域会被跳过并提示，而不是把值写进错误的字段
- 开启自动更新后会自动下载，「重启安装」可正常工作

## 1.0.0 — 2026-07-27

**MagiesPdf** 首个公开开源版本。

### 亮点

- **57 个本地 PDF 工具**（整理、转换、安全、编辑、高级）
- **抽屉侧栏** — 点击分类展开工具
- **流水线** — 内置预设，支持保存/加载与 JSON 导入导出
- **批量处理** — 支持递归选择文件夹
- **本地 REST API**（默认关闭，需 Bearer 令牌）
- **可见签名**（手绘 / 图片 / 文字）— 非证书数字签名
- **品牌图标** 覆盖 macOS / Windows / Linux 安装包

### 本版本明确不做

- 不做 PDF **证书**（PKCS#7 / X.509）签名或校验
- 不做安装包 **代码签名 / 公证**（开源分发）

### 首次打开（未签名安装包）

- **macOS**：安装后执行 `xattr -dr com.apple.quarantine /Applications/MagiesPdf.app`，或右键 → 打开
- **Windows**：SmartScreen → 更多信息 → 仍要运行
- **Linux AppImage**：`chmod +x` 后运行

### 平台（与 MagiesTerminal 一致）

- **macOS**：DMG + ZIP · arm64、x64（Intel）
- **Windows**：NSIS + portable + ZIP · x64、arm64
- **Linux**：AppImage、deb、rpm、pacman · x64、arm64

### 升级（双链）

- 设置 → 检查更新（仅安装包）
- 大陆优先 `dl.magies.top/magiespdf/stable`，海外优先 GitHub `Zhangwei930/MagiesPdf`
- 任一源失败自动切换另一源
